# Madeira & Arte

Landing page for **Madeira & Arte**, a custom woodworking shop. It presents the shop's services with starting prices, the reasons to choose it, payment options and a quote request form.

![Home page](docs/screenshot.webp)

**Live site:** [servicos-pro.vercel.app](https://servicos-pro.vercel.app)

## Sections

- **Hero** with rating, call to action and key numbers.
- **Services**: custom furniture, restoration and repairs, each with starting price, delivery time and warranty.
- **Why choose us**: warranty, punctuality and material quality.
- **Payment options**: PIX, card and cash, with their discounts and installment terms.
- **Quote request form**: name, phone, service type and project details (front-end only; no submission backend yet).
- **Footer** with contact information and social media links.

## Tech stack

Angular 19 (standalone components, server-side rendering with `@angular/ssr`) · TypeScript · CSS (responsive, no UI framework) · Vercel

## Getting started

```bash
npm install
npm start          # http://localhost:4200
npm run build      # production build with SSR
```
